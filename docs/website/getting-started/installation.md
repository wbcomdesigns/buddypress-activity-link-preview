# Installation

## Manual installation

1. Upload the `buddypress-activity-link-preview` folder to `/wp-content/plugins/`.
2. Activate the plugin through the Plugins menu in WordPress.
3. Make sure BuddyPress or BuddyBoss Platform is active.
4. Paste a link into an activity post. The preview appears automatically.

## No configuration needed

There is no settings page. The plugin works as soon as it is activated. There are no options to read or write and no admin screens beyond the dependency-missing notice.

## If the plugin will not stay active

If you activate the plugin while neither BuddyPress nor BuddyBoss Platform is active, WordPress deactivates it again on the next admin request and shows a notice. Activate BuddyPress or BuddyBoss Platform first, then activate this plugin.
